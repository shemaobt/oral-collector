# ADR-0003: Offline / persistence contract

- Status: Proposed
- Date: 2026-06-04
- Epic: E4 (Offline-First Data)

Offline-first behavior and the local persistence (drift) contract are not
formally specified — what is cached, when it syncs, and how conflicts resolve
is implicit in the code. Wave 1 E4 defines the offline / persistence contract
that every feature is expected to honor.
